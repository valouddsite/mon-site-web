Autres exports

Après le téléchargement

  1. Dézippe. Si le dossier ne contient pas de .fbx, lance blender -b -P build_fbx.py dans source/
  2. Ouvre le .fbx dans KsEditor, vérifie le sens des flèches AC_START, ajoute les textures, exporte en .kn5
  3. Les textures (route, bordures, herbe, murs, bâtiments, arbres) sont déjà dans le zip, à côté du .fbx. Pour les changer, remplace les PNG du dossier textures/ du projet
  4. Copie le dossier dans content/tracks/
  5. Roule un tour en jeu pour enregistrer le fast_lane.ai
